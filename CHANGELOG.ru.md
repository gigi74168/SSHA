# Журнал изменений

Все заметные изменения **`ssha`** описаны в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/) и [Семантическом версионировании](https://semver.org/lang/ru/). Заголовки разделов остаются на английском (`Added`, `Fixed`, `Changed`): `ssha` читает их, чтобы показывать новые возможности ✨ и исправления 🐛.

## [0.10.0] — 2026-11-24
### Added
- **Мониторинг CPU/RAM в реальном времени** рядом с каждой машиной в списке (`CPU 34% · RAM 71% (2,8/4 ГБ)`, обновление каждые 2 с, зелёный / жёлтый / красный в зависимости от нагрузки).
  - Включается для каждой машины отдельно: флажок `Мониторинг CPU/RAM` в форме, `Ctrl+P` или `/monitor [имя]` в интерфейсе, `ssha new --monitor` в командной строке.
  - Машины с Linux (чтение `/proc`); для других систем показывается `н/д`. `SSHA_NO_MONITOR=1` отключает его полностью.
- **6 языков интерфейса**: English, Français, Русский, Українська, Español, Italiano.
  - Выбор языка при первом запуске, по умолчанию выбран язык системы.
  - Сменить язык можно в любой момент: `/lang`, `ssha lang <код>` или переменная окружения `SSHA_LANG`.
  - `ssha --help` тоже переведён.
- **Список изменений в обновлении**: предложение обновиться теперь показывает новые возможности ✨ и исправления 🐛 каждой устанавливаемой версии на вашем языке.
- **Экран «Что нового»** при первом запуске после обновления, а также `ssha changelog` и `/changelog`, чтобы посмотреть его снова.
### Fixed
- Фоновые SSH-подключения больше не могут выводить текст или задавать вопросы поверх интерфейса (тихая проверка ключа хоста; изменённый ключ отклоняется и отображается как `⚠ ключ`).
### Changed
- Репозиторий, документация и установщики теперь на английском; журнал изменений доступен на 6 языках.
- Релизы GitHub теперь используют соответствующий раздел `CHANGELOG.md` в качестве описания.

## [0.9.0] — 2026-11-20
### Added
- **Полная поддержка macOS** (Apple Silicon `aarch64` и Intel `x86_64`): готовые бинарные файлы в GitHub Releases, автоопределение в `install.sh`, автообновление Mach-O, нативные диалоги Finder (`osascript`) и CI на `macos-latest`.
- **Импорт OpenSSH из `~/.ssh/config`**: новая команда `ssha import-ssh [путь]` и `/import-ssh` в интерфейсе (поддержка `Host`, `HostName`, `Port`, `User`, нескольких `IdentityFile`, `ProxyJump`, `LocalForward`, `ForwardAgent`).
- **Расширенные параметры SSH**:
  - **ProxyJump / бастион** (`-J` / `--proxy-jump` или импорт из `~/.ssh/config`) с цепочками переходов.
  - **Локальный проброс портов** (`-L local_port:remote_host:remote_port`, можно повторять).
  - **Перебор нескольких ключей** (несколько `IdentityFile`).
- **Необязательный режим мастер-пароля** (`ssha security enable-master-password` / `disable-master-password` / `status`) на основе **Argon2id + AES-256-GCM** для полностью переносимого `vault.enc`, при этом по умолчанию сохраняется режим автоматического ключа без пароля.
- **Документация и сообщество**: `CHANGELOG.md`, `CONTRIBUTING.md`, значки GitHub/CI/Release/лицензии в `README.md`, описание и темы GitHub.

## [0.8.0] — 2026-11-20
### Added
- **Автодополнение имён машин**: всплывающие подсказки над строкой ввода с первых набранных букв (и после `/files `, `/connect `, `/edit `, `/del `, `/test `), дополнение по **`Tab`**, навигация `↑`/`↓` и серая подсказка в строке.

## [0.7.0] — 2026-11-20
### Added
- **Полный импорт / экспорт конфигурации** (`ssha export` / `ssha import` и `/export` / `/import`), включая IP, порты, пользователей, пароли, ключи, группы и заметки.
- **Нативные окна выбора файлов и папок** (Проводник Windows, Linux `zenity`/`kdialog`, текстовый режим без графики) для рекурсивной отправки и загрузки файлов и папок в обе стороны.

## [0.6.0] — 2026-11-20
### Added
- **Автоматическое обнаружение и установка SFTP** на удалённых машинах с Linux при первом SFTP-подключении (`apt`, `pacman`, `dnf`, `yum`, `apk`, `zypper`, `opkg` + включение `Subsystem sftp internal-sftp` и перезагрузка `sshd`).

## [0.5.0] — 2026-11-20
### Added
- **Статус `UP` / `DOWN` в реальном времени** рядом с каждым IP + зелёный / красный индикатор **`●`** справа (неблокирующая параллельная TCP-проверка при запуске, обновление каждые 15 с или по `Ctrl+R` / `F5` / `/refresh`), также в `ssha list`.

## [0.4.0] — 2026-11-20
### Added
- **Автоматическое обнаружение обновлений на GitHub** при запуске с предложением прямо в терминале (`[Д/н]`) и атомарной заменой исполняемого файла через `self-replace` (Windows и Linux), а также команда `ssha update`.

## [0.3.1] — 2026-11-19
### Fixed
- Поддержка клавиш **AltGr** (`\`, `~`, `@`, `[`, `]`) на французских раскладках AZERTY в Windows в окнах SFTP.
- Автоматическое удаление кавычек, скопированных из Проводника Windows (`"C:\..."`), и префикса PowerShell `& '...'`.
- Раскрытие `~` в удалённых путях SFTP и полный вывод причин ошибок.

## [0.3.0] — 2026-11-19
### Added
- **Встроенный удалённый файловый менеджер SFTP** (`Ctrl+F`, `/files`, `ssha files`): навигация, прокручиваемый просмотр текста, рекурсивная загрузка (`Ctrl+D` / `ssha get`), рекурсивная отправка (`Ctrl+U` / `ssha put`), создание папок, переименование и рекурсивное удаление.

## [0.2.0] — 2026-11-19
### Changed
- Команда и пакет переименованы из `ssh-a` в **`ssha`**.

## [0.1.0] — 2026-11-19
### Added
- Первый публичный выпуск: интерфейс 100 % CLI/TUI на Rust (`ratatui`), нативный SSH-клиент (`russh`), автоматически зашифрованное хранилище AES-256-GCM (Windows DPAPI / Linux `0600`), установщики для Windows и Linux, CI/CD на GitHub Actions.
