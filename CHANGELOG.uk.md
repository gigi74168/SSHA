# Журнал змін

Усі помітні зміни **`ssha`** описано в цьому файлі.

Формат базується на [Keep a Changelog](https://keepachangelog.com/uk/1.1.0/) і [Семантичному версіонуванні](https://semver.org/lang/uk/). Заголовки розділів залишаються англійською (`Added`, `Fixed`, `Changed`): `ssha` читає їх, щоб показувати нові можливості ✨ і виправлення 🐛.

## [0.10.0] — 2026-11-24
### Added
- **Моніторинг CPU/RAM у реальному часі** поруч із кожною машиною у списку (`CPU 34% · RAM 71% (2,8/4 ГБ)`, оновлення кожні 2 с, зелений / жовтий / червоний залежно від навантаження).
  - Вмикається окремо для кожної машини: прапорець `Моніторинг CPU/RAM` у формі, `Ctrl+P` або `/monitor [назва]` в інтерфейсі, `ssha new --monitor` у командному рядку.
  - Машини з Linux (читання `/proc`); для інших систем показується `н/д`. `SSHA_NO_MONITOR=1` повністю вимикає його.
- **6 мов інтерфейсу**: English, Français, Русский, Українська, Español, Italiano.
  - Вибір мови під час першого запуску, за замовчуванням обрано мову системи.
  - Змінити мову можна будь-коли: `/lang`, `ssha lang <код>` або змінна середовища `SSHA_LANG`.
  - `ssha --help` також перекладено.
- **Список змін в оновленні**: пропозиція оновитися тепер показує нові можливості ✨ і виправлення 🐛 кожної версії, яку буде встановлено, вашою мовою.
- **Екран «Що нового»** під час першого запуску після оновлення, а також `ssha changelog` і `/changelog`, щоб переглянути його знову.
### Fixed
- Фонові SSH-підключення більше не можуть виводити текст або ставити запитання поверх інтерфейсу (тиха перевірка ключа хоста; змінений ключ відхиляється й показується як `⚠ ключ`).
### Changed
- Репозиторій, документація та інсталятори тепер англійською; журнал змін доступний 6 мовами.
- Релізи GitHub тепер використовують відповідний розділ `CHANGELOG.md` як опис.

## [0.9.0] — 2026-11-20
### Added
- **Повна підтримка macOS** (Apple Silicon `aarch64` та Intel `x86_64`): готові бінарні файли в GitHub Releases, автовизначення в `install.sh`, автооновлення Mach-O, нативні діалоги Finder (`osascript`) і CI на `macos-latest`.
- **Імпорт OpenSSH з `~/.ssh/config`**: нова команда `ssha import-ssh [шлях]` і `/import-ssh` в інтерфейсі (підтримка `Host`, `HostName`, `Port`, `User`, кількох `IdentityFile`, `ProxyJump`, `LocalForward`, `ForwardAgent`).
- **Розширені параметри SSH**:
  - **ProxyJump / бастіон** (`-J` / `--proxy-jump` або імпорт з `~/.ssh/config`) з ланцюжками переходів.
  - **Локальне перенаправлення портів** (`-L local_port:remote_host:remote_port`, можна повторювати).
  - **Перебір кількох ключів** (кілька `IdentityFile`).
- **Необов'язковий режим майстер-пароля** (`ssha security enable-master-password` / `disable-master-password` / `status`) на основі **Argon2id + AES-256-GCM** для повністю переносного `vault.enc`, при цьому за замовчуванням зберігається режим автоматичного ключа без пароля.
- **Документація та спільнота**: `CHANGELOG.md`, `CONTRIBUTING.md`, значки GitHub/CI/Release/ліцензії в `README.md`, опис і теми GitHub.

## [0.8.0] — 2026-11-20
### Added
- **Автодоповнення назв машин**: спливні підказки над рядком введення з перших набраних літер (і після `/files `, `/connect `, `/edit `, `/del `, `/test `), доповнення за **`Tab`**, навігація `↑`/`↓` і сіра підказка в рядку.

## [0.7.0] — 2026-11-20
### Added
- **Повний імпорт / експорт конфігурації** (`ssha export` / `ssha import` та `/export` / `/import`), включно з IP, портами, користувачами, паролями, ключами, групами та нотатками.
- **Нативні вікна вибору файлів і тек** (Провідник Windows, Linux `zenity`/`kdialog`, текстовий режим без графіки) для рекурсивного надсилання та завантаження файлів і тек в обидва боки.

## [0.6.0] — 2026-11-20
### Added
- **Автоматичне виявлення та встановлення SFTP** на віддалених машинах з Linux під час першого SFTP-підключення (`apt`, `pacman`, `dnf`, `yum`, `apk`, `zypper`, `opkg` + увімкнення `Subsystem sftp internal-sftp` і перезавантаження `sshd`).

## [0.5.0] — 2026-11-20
### Added
- **Статус `UP` / `DOWN` у реальному часі** поруч із кожним IP + зелений / червоний індикатор **`●`** праворуч (неблокувальна паралельна TCP-перевірка під час запуску, оновлення кожні 15 с або за `Ctrl+R` / `F5` / `/refresh`), також у `ssha list`.

## [0.4.0] — 2026-11-20
### Added
- **Автоматичне виявлення оновлень на GitHub** під час запуску з пропозицією прямо в терміналі (`[Т/н]`) та атомарною заміною виконуваного файлу через `self-replace` (Windows і Linux), а також команда `ssha update`.

## [0.3.1] — 2026-11-19
### Fixed
- Підтримка клавіш **AltGr** (`\`, `~`, `@`, `[`, `]`) на французьких розкладках AZERTY у Windows у вікнах SFTP.
- Автоматичне видалення лапок, скопійованих із Провідника Windows (`"C:\..."`), і префікса PowerShell `& '...'`.
- Розкриття `~` у віддалених шляхах SFTP і повний вивід причин помилок.

## [0.3.0] — 2026-11-19
### Added
- **Вбудований віддалений файловий менеджер SFTP** (`Ctrl+F`, `/files`, `ssha files`): навігація, прокручуваний перегляд тексту, рекурсивне завантаження (`Ctrl+D` / `ssha get`), рекурсивне надсилання (`Ctrl+U` / `ssha put`), створення тек, перейменування та рекурсивне видалення.

## [0.2.0] — 2026-11-19
### Changed
- Команду й пакет перейменовано з `ssh-a` на **`ssha`**.

## [0.1.0] — 2026-11-19
### Added
- Перший публічний випуск: інтерфейс 100 % CLI/TUI на Rust (`ratatui`), нативний SSH-клієнт (`russh`), автоматично зашифроване сховище AES-256-GCM (Windows DPAPI / Linux `0600`), інсталятори для Windows і Linux, CI/CD на GitHub Actions.
